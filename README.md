# AdiSnaps

AdiSnaps is an interactive frontend web application designed to showcase a photography portfolio and a functional mock e-commerce shop for camera gear.

## Features
* **Photography Portfolio:** Curated galleries featuring high-quality images from Georgia, Iceland, and Japan.
* **Gear Shop:** A mock storefront browsing camera bodies and lenses (Canon, Fujifilm, Sony).
* **Multi-page Navigation:** Includes dedicated pages for About, Contact, Gear, Photos, Shop, User Submissions, and more.
* **Client-Side Logic:** Implemented dynamic content rendering and interaction using JavaScript and TypeScript.

## Tech Stack
* HTML5
* CSS3
* JavaScript
* TypeScript

## Project Structure
* `/html/` - Core markup files for all application pages.
* `/css/` - Stylesheets for responsive design and layout (`AdiSnapsStyle.css`).
* `/js/` & `/typescript/` - Client-side scripts handling user interactions and dynamic rendering.
* `/pic/` - Organized image assets for galleries and the shop.

## How to Run
Since this is a static frontend application, no build steps or backend servers are required.
1. Clone the repository.
2. Navigate to the `/html/` directory.
3. Open `Welcome.html` or `AdiSnaps.html` directly in your preferred web browser.
